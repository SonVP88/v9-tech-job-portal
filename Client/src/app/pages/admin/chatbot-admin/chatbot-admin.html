info Cơ chế hoạt động & Phân bổ tải tự động

📌 Tính năng đảm nhận chính: Hệ thống tự động chia đều (Round-Robin) các phân hệ AI (Chatbot trả lời nhanh, Đánh giá CV, Soạn thảo Email, Soạn JD, Phỏng vấn ứng viên...) cho số lượng API Key đang có để tối ưu hóa hạn mức (Rate Limit) từ Google.

🛡️ Xác thực thời gian thực: Khi nhập key mới, máy chủ sẽ lập tức kiểm tra tính hợp lệ bằng một cuộc gọi HTTPS thử nghiệm tới Google API. Key chỉ được lưu trữ và đưa vào sử dụng khi việc xác thực thành công.

🔄 Kịch bản dự phòng xoay vòng: Nếu một API Key bị Google báo lỗi quá số lượt gọi (Rate Limit) hoặc bị người quản trị **Vô hiệu hóa**, hệ thống sẽ tự động chuyển các tác vụ của phân hệ đó sang các key hoạt động tốt khác (`Healthy`) theo thuật toán xoay vòng liên tục.

💡 Hướng dẫn vận hành: Hãy luôn duy trì ít nhất từ 2-3 API Keys để hệ thống tự cân bằng tải. Nếu một key bị báo đỏ hoặc tạm ngắt, hệ thống vẫn duy trì hoạt động bình thường mà không bị gián đoạn.
